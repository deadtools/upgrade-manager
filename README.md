# Upgrade Manager 3.7.4

Универсальная публичная сборка Upgrade Manager для резервного копирования, установки подписанных патчей, миграции проектов, удалённого управления и подключения через MCP/OAuth.

## Безопасность публичной версии

В репозитории **нет** локальных конфигураций, паролей, HMAC-ключей, repository key, OAuth-токенов, SMTP-паролей, runtime-хранилища или данных конкретного сайта.

После установки необходимо самостоятельно настроить центральный update-feed и ключ репозитория, если нужны сетевые обновления, Recovery по email или удалённое управление клиентскими сайтами.

## Установка

Исходники приложения находятся в каталоге `upgrade/`. Загрузите этот каталог в корень сайта как `/upgrade/` и откройте `/upgrade/setup.php`.

Подробности: `upgrade/README_INSTALL_RU.md`.
